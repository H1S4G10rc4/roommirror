# Room mirror

ウェブカメラ映像を車のルームミラーに近い4:1のウィンドウで表示するデスクトップアプリです。

- ウィンドウの縦横比を4:1に固定
- 映像は引き伸ばさず、ウィンドウ全体を埋める
- 映像を常に左右反転して表示
- はみ出す縦方向は映像の上側を切り落とし、下側の画角を優先表示
- OSのタイトルバーを表示しない（映像部分のドラッグで移動）
- カメラ切替
- 最前面表示のON/OFF
- 録画や外部送信は行わない

```bash
npm install
npm start
```
